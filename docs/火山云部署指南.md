# 贷后案件管理系统 - 火山云服务器部署指南

- **IP 地址**: 101.96.214.104
- **域名**: scholargl.cn

## 第一阶段：服务器初始配置（仅需执行一次）

### 步骤 1：连接服务器

使用以下任一方式连接服务器：

**方式A：使用本地终端（Mac/Linux）**
```bash
ssh root@101.96.214.104
```

**方式B：使用 PuTTY（Windows）**
1. 下载 PuTTY
2. 主机名输入: 101.96.214.104
3. 端口: 22
4. 连接类型: SSH
5. 点击"打开"
6. 输入用户名: root 和密码

---

### 步骤 2：运行一键部署脚本

连接成功后，在服务器终端执行以下命令：

```bash
# 下载一键部署脚本
cd /tmp
curl -O https://您的脚本地址/deploy.sh

# 或者手动创建脚本（复制下方内容到文件）
vi /tmp/deploy.sh
# 按 i 粘贴内容
# 按 Esc，输入 :wq 保存

# 运行脚本
chmod +x /tmp/deploy.sh
/tmp/deploy.sh
```

**⚠️ 如果网络无法下载，请跳到"手动部署"部分**

## 第二阶段：上传项目代码

### 方式A：使用 Git（推荐）

```bash
cd /opt/loan-system
git clone https://github.com/您的用户名/loan-system.git .
```

### 方式B：使用 SCP 上传（Windows）

1. 打开 PowerShell 或命令提示符
2. 进入本地项目目录
3. 执行：
```bash
scp -r ./* root@101.96.214.104:/opt/loan-system/
```

### 方式C：使用 FTP

1. 在服务器安装 vsftpd:
```bash
apt install -y vsftpd
systemctl start vsftpd
systemctl enable vsftpd
```

2. 使用 FileZilla 等 FTP 软件连接:
   - 主机: 101.96.214.104
   - 用户名: root
   - 密码: 您的服务器密码
   - 端口: 22

## 第三阶段：启动应用

```bash
cd /opt/loan-system

# 安装依赖
pnpm install

# 构建
pnpm build

# 启动
pm2 start pnpm --name "loan-system" -- start

# 保存配置（开机自启）
pm2 save
pm2 startup
```

## 配置域名（可选）

如果您想使用 scholargl.cn 域名访问：

### 方式A：Nginx 反向代理

```bash
# 安装 Nginx
apt install -y nginx

# 创建配置
cat > /etc/nginx/sites-available/loan-system << 'EOF'
server {
    listen 80;
    server_name scholargl.cn;

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
EOF

# 启用配置
ln -sf /etc/nginx/sites-available/loan-system /etc/nginx/sites-enabled/
nginx -t
systemctl reload nginx
```

### 方式B：配置 SSL（可选）

```bash
# 安装 Certbot
apt install -y certbot python3-certbot-nginx

# 获取 SSL 证书
certbot --nginx -d scholargl.cn
```

## 故障排查

### 问题1：端口被占用
```bash
# 查看端口占用
lsof -i:5000

# 杀死占用进程
kill -9 <PID>
```

### 问题2：数据库连接失败
```bash
# 检查 PostgreSQL 状态
systemctl status postgresql

# 检查连接
su - postgres
psql -d loandb -U loanadmin
\q
exit
```

### 问题3：应用无法启动
```bash
# 查看详细日志
pm2 logs loan-system --err --lines 100

# 尝试前台运行查看错误
cd /opt/loan-system
pnpm start
```
