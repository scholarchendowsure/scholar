# 🔰 零基础部署指南 - 火山云 ECS

> 目标服务器: 101.96.214.104
> 预计时间: 30分钟
> 难度: ⭐ (有手就行)

---

## 第一步：连接服务器

### Windows 用户

1. 下载 PuTTY: https://www.putty.org/
2. 打开 PuTTY
3. Host Name 填: `101.96.214.104`
4. Port 填: `22`
5. 点击 "Open"
6. 弹出窗口问用户名，输入: `root`
7. 输入密码（输入时看不见字符，正常的）

### Mac 用户

1. 打开"终端" (Terminal)
2. 输入:
```
ssh root@101.96.214.104
```
3. 输入密码

---

## 第二步：复制粘贴这段代码

在 PuTTY/终端 里，**复制**下面这段代码，**右键粘贴**，按**回车**：

```
apt update && apt install -y docker.io docker-compose && systemctl start docker && systemctl enable docker
```

等待出现命令提示符（大概30秒）...

看到类似 `$` 或 `root@` 就说明成功了！

---

## 第三步：创建目录

复制粘贴这段代码：

```
mkdir -p /opt/loan-system
```

---

## 第四步：上传代码

### 方法A：用 WinSCP（Windows推荐）

1. 下载 WinSCP: https://winscp.net/
2. 新建连接：
   - 主机名: `101.96.214.104`
   - 用户名: `root`
   - 密码: 您的密码
3. 连接后，左边选您电脑的项目文件夹
4. 右边选 `/opt/loan-system`
5. 拖动文件过去

### 方法B：用命令上传（Mac/Linux）

在**您本地电脑的终端**执行（不是服务器）：

```
scp -r /Users/您的用户名/项目路径/* root@101.96.214.104:/opt/loan-system/
```

---

## 第五步：启动服务

回到 PuTTY/终端（服务器），复制粘贴：

```
cd /opt/loan-system && docker-compose up -d
```

等待 3-5 分钟...

看到 `done` 或 `Starting... done` 就成功了！

---

## 第六步：验证

打开浏览器，访问：

```
http://101.96.214.104:5000
```

🎉 看到系统界面就是成功了！

---

## 以后更新代码

1. 重新上传代码到 `/opt/loan-system`
2. 在服务器执行：
```
cd /opt/loan-system && docker-compose down && docker-compose up -d --build
```

---

## 出问题了？

### 看不到网站？

复制粘贴：
```
docker-compose logs
```
把显示的内容发给我。

### 想重启？

复制粘贴：
```
cd /opt/loan-system && docker-compose restart
```

### 停止服务？

复制粘贴：
```
cd /opt/loan-system && docker-compose down
```
