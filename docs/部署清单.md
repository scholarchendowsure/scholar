# 部署清单 - 火山云 ECS (101.96.214.104)

## 部署前检查清单

- [ ] 准备好服务器密码
- [ ] 项目代码已打包成 zip 或有 Git 仓库地址
- [ ] 浏览器能访问服务器 IP

---

## 一键复制命令清单

### 1️⃣ 安装 Docker（只需执行一次）

```bash
apt update && apt install -y docker.io docker-compose && systemctl start docker && systemctl enable docker
```

### 2️⃣ 上传代码

在本地电脑执行（不是服务器）：

```bash
scp -r ./您的项目代码 root@101.96.214.104:/opt/loan-system/
```

### 3️⃣ 启动服务

```bash
cd /opt/loan-system && docker-compose up -d
```

### 4️⃣ 验证

```bash
curl localhost:5000
```

---

## 出错？试试这些

### 重新部署
```bash
cd /opt/loan-system && docker-compose down && docker-compose up -d
```

### 查看日志
```bash
cd /opt/loan-system && docker-compose logs
```

### 查看实时日志
```bash
cd /opt/loan-system && docker-compose logs -f
```
